# Teal Ink (青墨)

- Reserve the seven fixed swatches for marks and samples. Assign color by role: warm neutrals dominate, teal marks the primary action or a focal accent, and sage supports. Use ink on teal fills and neutral primary/secondary text for reading
- Anchor light work in warm paper and dark work in warm ink. Separate base, local, and raised layers with small lightness shifts or restrained edges. Calibrate each mode separately. Keep grounds free of decorative gradients, grids, noise, blur, and glow
- Build hierarchy with type and spacing: group related content closely, use sans for reading, serif for display, and mono for code where useful
- Where applicable, use muted green for success, purple for info, amber for warning, and red for error. Keep meanings consistent and pair color with text or shape. In interactive work, keep teal-family selection and focus distinct from hover; lighten accent on hover, darken on press
- Adapt scale and interaction to the medium. Check hierarchy, legibility, and contrast in the intended output

Use [exact color values](references/colors.md) when specifying colors. Read [web integration](references/integration.md) only for browser work
